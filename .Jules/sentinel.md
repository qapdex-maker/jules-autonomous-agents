## 2026-07-09 - Prompt Injection Safety Guardrails
**Learning:** In a repository containing AI agent prompts, prompt injection (and indirect prompt injection) is a critical security vulnerability. If agents treat untrusted external content or user data as instructions rather than raw data, it can lead to unauthorized actions.
**Action:** Enhance the Sentinel security agent's scanning guidelines to include detection of prompt injection risks and untrusted input safety checks.
